# 常用表情引用存储

常用分组仍向组件提供完整 Emoji JSON 对象，底层持久化仅保存源分组 ID、源表情 ID、使用次数与最近使用时间，不重复复制源图片 URL、名称、标签或 customOutput。加载时自动解析引用；更新源分组后常用表情随之更新。

旧版复制式常用表情在加载时按源 ID / URL 自动迁移，合并重复项并累计次数。无法匹配源的历史图片暂时完整保留，避免迁移丢失；已删除或归档源的引用不渲染破损图片。使用次数不再进行十二小时衰减，每次使用加一。

Popup/侧边栏显示即时次数徽标；“所有表情”和全局搜索排除常用分组的重复副本。后台将使用记录串行处理，避免连续操作互相覆盖。
